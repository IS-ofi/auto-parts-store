# 🚗 auto-parts-store — Інтернет-магазин автомобільних запчастин

## 💡 Ідея застосунку

**AutoParts Hub** — це сучасна вебплатформа для зручного пошуку, вибору та купівлі автомобільних запчастин. Застосунок створений для того, щоб об'єднати власників автомобілів і надійних постачальників автокомпонентів в одному інтуїтивно зрозумілому інтерфейсі, мінімізуючи час на пошук потрібної деталі.

## 🎯 Мета та ціль проєкту

- **Головна мета:** Надати користувачам швидкий, точний та безпечний доступ до широкого асортименту автомобільних запчастин з можливістю підбору за маркою, моделлю та VIN-кодом авто.
- **Бізнес-ціль:** Створити зручний маркетплейс автотоварів із високою швидкістю роботи, простим адмініструванням товарної бази та ефективною системою обробки замовлень.

## ⚙️ Основні можливості (функціонал)

### Для користувачів (клієнтів):

- 🔍 **Зручний каталог та пошук:** Фільтрація товарів за категоріями (двигун, гальмівна система, підвіска тощо), брендом, ціною та артикулом.
- 🚗 **Підбір за авто:** Можливість пошуку запчастин відповідно до марки, моделі, року випуску та модифікації автомобіля.
- 🛒 **Кошик та оформлення замовлення:** Додавання товарів до кошика, керування кількістю та оформлення покупки з вибором способу доставки й оплати.
- 👤 **Особистий кабінет:** Перегляд історії замовлень та збереження контактних даних.

### Для адміністраторів:

- 📦 **Керування каталогом (CRUD):** Додавання, редагування та видалення карток товарів, керування залишками на складі.
- 📋 **Обробка замовлень:** Перегляд вхідних замовлень від клієнтів та зміна їх статусів (у обробці, відправлено, виконано).

## 🛠️ Стек технологій

Проєкт розроблений із використанням сучасного та гнучкого стека технологій (Full-stack JavaScript):

- **Frontend:**
  - `HTML5` — семантична структура сторінок.
  - `CSS3` — адаптивний та сучасний дизайн інтерфейсу.
  - `JavaScript (ES6+)` — інтерактивність сторінок, валідація форм, асинхронні запити (Fetch API) до бекенду.

- **Backend:**
  - `Node.js` — середовище виконання JavaScript на сервері.

- **База даних:**
  - `MongoDB` — документоорієнтована NoSQL база даних для гнучкого зберігання інформації про товари, категорії, користувачів та замовлення.
